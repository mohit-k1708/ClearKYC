# Requirements traceability (Phase 5, updated in Phases 6 and 7)

Every requirement of the ClearKYC challenge, where it is implemented, how it was verified and whether it is complete. Status values: **Complete**, **Partial**, **Missing**, **Blocked**. "Evidence" names the test file or command that actually exercises the requirement; the numbers of the latest runs are in `docs/submission-readiness.md`. A requirement is only marked Complete when something executable checks it.

How to read the verification column

| Short name | What it is | Command |
|---|---|---|
| backend tests | `server/tests/*.test.js` (node:test) against the dedicated test database | `npm test` |
| browser tests | Puppeteer scripts in `tests/browser/` against a test API + web app on the test database | `npm run test:browser` |
| dataset checks | generator, edge-case, detector, validation, export and reproducibility tests | `npm run test:edge-cases`, `npm run test:phase4`, `npm run dataset:all` |
