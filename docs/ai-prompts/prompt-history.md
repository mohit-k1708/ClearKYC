## 5. KYC Completeness Calculation

Create a backend function that calculates the customer's KYC completeness percentage.

Use this formula:

**Completeness % = (Number of verified mandatory requirements / Total mandatory requirements) × 100**

Example:

A customer has 5 mandatory documents.

* PAN: Verified
* Address Proof: Verified
* Photograph: Pending
* Bank Statement: Missing
* Additional Evidence: Verified

Completeness = (3 / 5) × 100 = 60%.

### Display

* 100% — Complete
* 1–99% — Partially Complete
* 0% — Not Started

Also show:

* Total mandatory documents.
* Verified documents.
* Missing documents.
* Pending verification documents.
* Rejected documents.
* Expired documents.

Calculate completeness from database records. Never store a randomly generated completeness percentage.

If a mandatory document is expired, it must not count as a currently valid verified requirement.
